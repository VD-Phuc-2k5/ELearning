## Reporting a Vulnerability

Please report suspected vulnerabilities privately using GitHub Security
Advisories for this repository:
https://github.com/OWNER/REPOSITORY/security/advisories/new

If private reporting through GitHub is unavailable, email the maintainers at
security@example.com. Please do not open public GitHub issues for security
reports.

To help us triage the issue quickly, include:

- A clear description of the vulnerability and its potential impact.
- The affected version(s), commit hash, configuration, and environment.
- Step-by-step reproduction instructions or a proof of concept.
- Any relevant logs, stack traces, screenshots, or packet captures.
- Suggested mitigations or fixes, if known.

We will acknowledge receipt within 3 business days and aim to provide an
initial triage update within 7 business days. After validation, we will keep
you informed of remediation progress and coordinated disclosure timing. If the
report is out of scope, not reproducible, or otherwise not accepted, we will
let you know with the reason when possible.
